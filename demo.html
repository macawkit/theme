02

Visual language

surfaces · markers · layers
Panel .panel A region of the page and the outermost surface. Everything else lives inside one.
Well .well Sunk into a surface. Holds a group of data or controls so they read as one.
Card .card A self-contained unit inside a panel, made to be repeated.
Box .box · .active The smallest frame: one glyph or one value. Lights up when active.

Value
Divider dl · table Rows are separated by hairlines, never boxed. Lines stay quieter than content.
Tabs [role=tablist] · nav.tabs A choice along one axis. Only the selected tab is marked; the rest stay flat.
Toggle [aria-pressed] · label.button > input A button that holds a state, plain, secondary or ghost. It is lit by being on; the pointer only hints.
Tag Badge Tone
Tag · Badge .tag · .badge · .<tone> Inline markers. A tag names something; a badge reports a state and carries a light.
